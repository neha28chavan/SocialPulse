A full-stack, distributed social media application built using Spring Boot, Spring Cloud (Microservices), and  frontend. The architecture leverages an API Gateway for centralized routing, Eureka for service discovery, and real-time WebSocket communication for live chat.
🛠️ Tech Stack
Backend: Java 17, Spring Boot, Spring Cloud (Eureka, Gateway), Spring Data JPA, MySQL 
Frontend: React.js, Context API, Axios, SockJS, Stomp.js (WebSocket)
API Testing & Routing: Postman, Spring Cloud Gateway (port 8080)
Development Tools: Eclipse IDE, VS Code, Git, Maven
